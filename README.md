# University Transport Management and Billing System

## Overview
A console-based, menu-driven system to automate university transport registration, route allocation, billing, and reporting. Built using Object-Oriented Programming principles.

## Features
- User management (Admin, Student, Driver)
- Vehicle management (Bus, Van)
- Route management
- Transport registration with capacity checks
- Billing & reporting with late fee handling
- Persistent storage using file handling

## Technologies
- C++ (OOP concepts: inheritance, polymorphism, templates)
- File handling for persistence
- Dynamic memory management
